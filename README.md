# Dokumentacja API

Adres dokumentacji: http://localhost:8080/v3/api-docs
aby wyłączyć na produkcji należy zmienić flagę "springdoc.api-docs.enabled" na false w application.properties

Adres dokumentacji UI: http://localhost:8080/swagger-ui/index.html
aby wyłączyć na produkcji należy zmienić flagę "springdoc.swagger-ui.enabled" na false w application.properties
